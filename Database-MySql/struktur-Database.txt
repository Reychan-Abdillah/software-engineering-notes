# MySQL Fundamentals — Database Setup & Basic SQL

## 1. Memahami Database, Table, dan Column

Sebelum menggunakan MySQL, pahami tiga istilah dasar berikut:

- **Database**: tempat untuk mengelompokkan dan menyimpan berbagai tabel yang digunakan oleh aplikasi.
- **Table**: tempat menyimpan kumpulan data dengan struktur tertentu.
- **Column**: atribut atau jenis informasi yang dimiliki setiap data dalam tabel.

Contoh sederhana:

Dalam aplikasi CRUD, kita memiliki database `crud_app` yang berisi tabel `products`. Tabel tersebut memiliki kolom `id`, `name`, `price`, dan `stock`.

---

## 2. Persiapan Database

Tahapan yang sudah dilakukan untuk proyek CRUD App:

1. Menginstal MySQL Server dan MySQL Workbench.
2. Membuat koneksi ke MySQL Server.
3. Membuat database `crud_app`.
4. Membuat tabel `products`.
5. Memastikan struktur tabel sudah benar.
6. Memasukkan beberapa data produk sebagai contoh.
7. Memahami operasi dasar SQL: `INSERT`, `SELECT`, `UPDATE`, dan `DELETE`.

## 3. Membuat dan Menggunakan Database

### Membuat database

```sql
CREATE DATABASE crud_app;
```

Digunakan untuk membuat database baru bernama `crud_app`.

### Melihat daftar database

```sql
SHOW DATABASES;
```

Digunakan untuk menampilkan daftar database yang tersedia di MySQL Server.

### Memilih database

```sql
USE crud_app;
```

Digunakan untuk memilih database `crud_app` sebagai database aktif. Perintah SQL berikutnya akan dijalankan pada database tersebut, kecuali kita memilih database lain.

---

## 4. Membuat Tabel

Setelah database dibuat dan dipilih, kita bisa membuat tabel untuk menyimpan data produk.

```sql
CREATE TABLE products (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    stock INT NOT NULL
);
```

Penjelasan struktur tabel:

| Kolom   | Tipe Data       | Fungsi                                                |
| ------- | --------------- | ----------------------------------------------------- |
| `id`    | `INT`           | Menyimpan angka sebagai identitas produk.             |
| `name`  | `VARCHAR(100)`  | Menyimpan nama produk maksimal 100 karakter.          |
| `price` | `DECIMAL(10,2)` | Menyimpan harga dengan dua angka di belakang desimal. |
| `stock` | `INT`           | Menyimpan jumlah stok produk.                         |

### Memahami atribut penting

- **AUTO_INCREMENT**: membuat nilai ID bertambah secara otomatis ketika data baru dimasukkan.
- **PRIMARY KEY**: menetapkan kolom sebagai identitas unik setiap baris. Nilainya tidak boleh duplikat dan tidak boleh NULL.
- **NOT NULL**: mewajibkan kolom memiliki nilai, sehingga tidak boleh berisi NULL.
- **DECIMAL(10,2)**: tipe data angka desimal dengan total maksimal 10 digit, termasuk 2 digit di belakang koma.

`DECIMAL` cocok untuk menyimpan harga karena memiliki presisi tetap.

### Melihat tabel yang tersedia

```sql
SHOW TABLES;
```

Digunakan untuk menampilkan daftar tabel dalam database yang sedang aktif.

### Melihat struktur tabel

```sql
DESCRIBE products;
```

Menampilkan informasi struktur tabel, seperti:

- Nama kolom.
- Tipe data.
- Apakah kolom boleh berisi NULL.
- Primary Key.
- Atribut tambahan seperti `AUTO_INCREMENT`.

## 5. Operasi Dasar SQL (CRUD)

CRUD merupakan singkatan dari:

- **Create**: menambahkan data.
- **Read**: membaca atau menampilkan data.
- **Update**: memperbarui data.
- **Delete**: menghapus data.

### A. INSERT — Menambahkan Data

Digunakan untuk memasukkan data baru ke dalam tabel.

```sql
INSERT INTO products (name, price, stock)
VALUES ('Laptop', 8000000, 5);
```

Artinya:

- `INSERT INTO products`: memasukkan data ke tabel `products`.
- `(name, price, stock)`: menentukan kolom yang akan diisi.
- `VALUES`: menentukan nilai untuk setiap kolom tersebut.

Kolom `id` tidak perlu diisi karena sudah menggunakan `AUTO_INCREMENT`.

### B. SELECT — Menampilkan Data

Digunakan untuk mengambil atau membaca data dari tabel.

```sql
SELECT * FROM products;
```

Penjelasan:

- `SELECT`: memilih data yang ingin ditampilkan.
- `*`: mengambil semua kolom.
- `FROM products`: mengambil data dari tabel `products`.

Jika hanya ingin menampilkan kolom tertentu:

```sql
SELECT name, price FROM products;
```

Query tersebut hanya menampilkan kolom `name` dan `price`.

### C. WHERE — Memfilter Data

`WHERE` digunakan untuk menentukan kondisi agar hanya baris yang memenuhi kondisi tersebut yang ditampilkan atau diproses.

Contoh:

```sql
SELECT * FROM products
WHERE price > 1700000;
```

Artinya, tampilkan semua kolom dari produk yang memiliki harga lebih dari 1.700.000.

`WHERE` juga bisa digunakan bersama `UPDATE` dan `DELETE`, bukan hanya `SELECT`.

### D. UPDATE — Memperbarui Data

Digunakan untuk mengubah nilai pada data yang sudah tersimpan.

Contoh:

```sql
UPDATE products
SET price = 150000
WHERE name = 'Charger';
```

Artinya, ubah harga produk bernama Charger menjadi 150.000.

**Mengapa WHERE penting?**

Misalnya ada dua produk dengan nama yang sama. Jika kita ingin mengubah hanya satu produk tertentu, lebih aman menggunakan `id` karena setiap produk memiliki ID unik.

```sql
UPDATE products
SET price = 150000
WHERE id = 1;
```

Dengan begitu, hanya produk dengan ID 1 yang diperbarui.

### E. DELETE — Menghapus Data

Digunakan untuk menghapus baris data dari tabel.

Contoh:

```sql
DELETE FROM products
WHERE id = 1;
```

Artinya:

- `DELETE`: menghapus data.
- `FROM products`: dari tabel `products`.
- `WHERE id = 1`: hanya menghapus baris dengan ID 1.

**Penting: pahami risiko penggunaan DELETE.**

```sql
DELETE FROM products;
```

Perintah tersebut menghapus **seluruh baris data** dalam tabel `products` karena tidak memiliki kondisi `WHERE`.

Tabel dan struktur kolomnya tetap ada, tetapi semua datanya terhapus.

Biasakan memeriksa kondisi menggunakan `SELECT` sebelum menjalankan `UPDATE` atau `DELETE`.

Contoh:

```sql
SELECT * FROM products
WHERE id = 1;
```

Pastikan data yang akan diubah atau dihapus sudah benar.

## 6. Memahami Risiko Kehilangan Data

Secara default, MySQL menggunakan `autocommit` sehingga setiap perintah perubahan data yang berhasil biasanya langsung di-commit.

Artinya, setelah perintah `DELETE` berhasil di-commit, kita tidak bisa begitu saja menekan Undo atau menggunakan `ROLLBACK` untuk mengembalikan data tersebut.

Beberapa mekanisme pemulihan data:

- **ROLLBACK**: membatalkan perubahan yang belum di-commit dalam transaksi yang masih terbuka.
- **BACKUP**: memulihkan data dari salinan database yang dibuat sebelumnya.
- **BINARY LOG**: mencatat perubahan database jika binary logging aktif dan transaksi yang dibutuhkan masih tersimpan. Log ini dapat digunakan untuk pemulihan ke titik waktu tertentu dengan prosedur yang tepat.

Catatan: mengaktifkan binary log saja tidak menjamin semua data lama bisa dipulihkan. Riwayat transaksi yang dibutuhkan harus benar-benar tersedia di dalam log.

## 7. Ringkasan Perintah SQL

| Perintah          | Fungsi                          |
| ----------------- | ------------------------------- |
| `CREATE DATABASE` | Membuat database.               |
| `SHOW DATABASES`  | Melihat daftar database.        |
| `USE`             | Memilih database aktif.         |
| `CREATE TABLE`    | Membuat tabel.                  |
| `SHOW TABLES`     | Melihat daftar tabel.           |
| `DESCRIBE`        | Melihat struktur tabel.         |
| `INSERT INTO`     | Menambahkan data.               |
| `SELECT`          | Membaca atau menampilkan data.  |
| `WHERE`           | Menentukan kondisi atau filter. |
| `UPDATE`          | Memperbarui data.               |
| `DELETE`          | Menghapus data.                 |

3. Memahami relasi antar tabel dan konsep dasar database design.
